# Interface languages

Tayfa ships in Turkish and English. Turkish is the source language: the Turkish text written in the
code is the message key, and English lives in catalogs keyed by that Turkish text.

## How the language is chosen

- **Desktop:** Settings → Appearance → "Dil / Language" offers System, Türkçe and English. The main
  process stores the choice in `locale.json` in the profile folder and hands it to the window
  through the preload (`window.rooms.locale`). Changing it rebuilds the native menus and reloads the
  window.
- **System:** Turkish when the system's first language is Turkish or its region is Turkey (macOS
  reports `en-TR` for English set up in Turkey); English everywhere else.
- **Overrides:** `ROOMS_LOCALE=tr|en` pins the main process (CI machines run in English, and most
  native checks look for Turkish text). The browser build reads `?lang=tr|en`, then its own stored
  choice. Tests pin Turkish through `tests/setup-locale.ts`.
- **Invite page (`/davet`):** follows the browser's `Accept-Language`.
- **iPhone:** follows iOS's per-app language (Settings → Tayfa → Language): Turkish for Turkish,
  English for every other language. Unlike the desktop, an English iPhone set up in Turkey gets
  English. String Catalogs (`.xcstrings`) hold Turkish keys with English values.

## Writing interface text

```ts
import { t } from './i18n'; // renderer; main process and packages import from '@rooms/i18n'

t('Kaydet');
t('{name} odaya katıldı', { name });
t('{count} kişi', { count }); // English catalog: { one: '{count} person', other: '{count} people' }
```

- Keep the Turkish wording exactly as it is; only template literals change shape:
  `` `${name} katıldı` `` becomes `t('{name} katıldı', { name })`.
- Pass `t()` a plain string literal. A template, a concatenation or a variable cannot be checked
  against the catalog. Where text comes from a table (`{ label: 'Görünüm' }`), wrap the literal in
  the table: `{ label: t('Görünüm') }`.
- One sentence is one message. Do not glue translated fragments together; word order differs.
  When a sentence holds markup (`<strong>`), translate the pieces around it and keep each piece a
  readable phrase.
- English plurals use `{ one, other }` and read `count`. Turkish never needs plural forms.
- In the renderer, `t()` may run at module level: the language is fixed before any module that
  imports `./i18n` evaluates. In the Electron main process the language is configured after `ready`,
  so call `t()` inside functions only.
- Dates and numbers use `locale` (renderer, from `./i18n`) or `intlLocale()`; never a literal
  `'tr-TR'`. Turkish-specific text processing (case folding Turkish titles, parsing Turkish provider
  data) keeps `'tr'` and carries an `i18n-ignore` comment.
- Errors shown to people are translated where they are thrown: `throw new Error(t('…'))`. Error
  codes from services are mapped in `errorMessages` (`apps/desktop/src/i18n.ts`) and translated by
  `uiError`.
- The legacy `tr(englishKey)` lookup still works: English returns the key, Turkish returns
  `trMessages`/`activityMessages`. Do not add new `tr()` keys; use `t()` with Turkish.
- A lambda parameter named `t` shadows the translator; rename it (`tab`, `item`, `track`).

Never translate: what people type (messages, names, channel and server names), development fixtures
under `src/dev`, tests, console logs, internal error codes, key names, and brand or product names
(Tayfa, YouTube, IPTV, Xtream, Real-Debrid, TMDB, IMDb, Letterboxd, LiveKit, Stoat,
OpenRouter, Codex, Claude).

## Catalogs

English lives in `apps/desktop/src/locales/en/<group>.ts`, one file per area: `core`, `shell`,
`social`, `media`, `settings`, `cinema`, `assistant`, `games`, `main`. A message used by several
areas may appear in more than one file, but with the same English. `tests/i18n-catalog.test.ts`
checks that every `t()` literal has English, placeholders match, groups agree, no Turkish is left in
English, and no entry is unused.

`node scripts/i18n-scan.mjs [paths]` lists Turkish-looking text outside `t()`/`tr()`. Mark text that
must stay Turkish with an `// i18n-ignore` comment on the same or the previous line (JSX:
`{/* i18n-ignore */}`).

## English style

- US spelling (color, favorite, canceled). Sentence case for labels, buttons and titles, as in
  Turkish. Text written in capitals in Turkish (eyebrow labels) stays in capitals.
- Friendly and plain, second person, like the Turkish `sen`. Short buttons: "Save", "Cancel",
  "Try again". No exclamation marks unless the Turkish has one.
- Ellipsis is the single character `…`, as in the source. Keep `·` separators.
